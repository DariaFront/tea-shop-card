# Teaboom — карточка товара «Ананасовый улун»

Адаптивная демонстрационная верстка **верхней части карточки товара** по тестовому заданию Teaboom.ru. 

## Что реализовано

- Семантический HTML5: `article`, `nav`, `fieldset`, `legend`, `output`, заголовки.
- Четыре фасовки (100/500/1000/5000 г) с переключением цены, старой цены, артикула и выделения выбранного варианта.
- Кнопка «В корзину»: обычное состояние, hover/focus/active и демонстрационный отклик без backend.
- Короткое описание, категория, фотография товара.
- Адаптивная верстка на CSS Grid/Flexbox для 1440 / 768 / 375 px (и промежуточных ширин).
- Управление с клавиатуры (нативные radio), видимый focus и поддержка `prefers-reduced-motion`.
- Без фреймворков, Bootstrap, сборщиков и сторонних JS-библиотек.

## Запуск

Откройте `index.html` в браузере. Никакие зависимости устанавливать не нужно. При размещении на статическом хостинге достаточно загрузить **всю папку проекта** с сохранением структуры.

Для локальной проверки можно использовать любой статический сервер, например:

```bash
python -m http.server 8000
```

После запуска откройте http://localhost:8000/.

## Структура

```text
index.html                  — HTML-разметка
styles.css                  — стили, токены и медиазапросы
script.js                   — переключение фасовок и демо-кнопка
assets/tea-placeholder.svg  — локальная резервная иллюстрация
```

## Откуда данные

Название, фасовки, артикулы, цены, состав и ссылка на изображение взяты из [карточки товара Teaboom](https://teaboom.ru/product/ananasovij-ulun). Основное фото подгружается с `media.teaboom.ru` (CDN оригинального сайта). Если оно недоступно, автоматически показывается локальная резервная иллюстрация. Для полностью автономного коммерческого размещения изображение следует сохранить локально при наличии разрешения правообладателя.

## Что не входит в демо

Нет backend, API-корзины, авторизации и реальных покупок. Кнопка «В корзину» показывает подтверждение выбранной фасовки — это осознанно соответствует ограничениям ТЗ.


## Подход к выполнению

Для ускорения подготовки использовался ИИ как инструмент генерации первоначального кода; структура, UX и проверка функций требуют ручной ревизии. Компонент спроектирован независимо от legacy-зависимостей сайта, чтобы его было проще интегрировать и сопровождать.

## Ручная проверка перед сдачей

1. При выборе каждой фасовки проверить подсветку, цену и артикул.
2. Проверить обычное состояние кнопки, наведение, фокус через Tab и тестовое нажатие.
3. В инструментах разработчика проверить отсутствие горизонтальной прокрутки на ширинах 1440, 768 и 375 px.
4. Проверить отображение реальной фотографии товара; если CDN недоступен, должна появиться резервная иллюстрация.
